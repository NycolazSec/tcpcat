Version history & changelog — semantic versioning

v1.0.0 September 2026 Latest

First stable release. eBPF/AF_XDP acceleration, WASM detection engine, and the safe-production assessment profile.

  • AddedeBPF/AF_XDP packet capture path for wire-speed scans.
  • AddedWASM protocol dissector sandbox (Rust, C, Go, AssemblyScript).
  • Added--scope-file, --profile safe-production, and --audit-log options.
  • AddedJSON, SARIF, and JSONL report output.
Binaries: linux/amd64, linux/arm64 · Signed checksums (SHA256SUMS) available on the GitHub release page.
v0.9.0 August 2026

Beta. Core scanning engine, IDS/IPS visibility profiles, and initial CLI.

  • AddedL3–L7 variation controls (--evasion) for authorized visibility testing.
  • ChangedDefault scan timeout reduced for faster authorized inventories.
  • FixedIPv6 fragmentation edge case in the topology mapper.
v0.1.0 June 2026

Initial public prototype.

  • AddedMulti-protocol enumeration: TCP, UDP, ICMP.
